# ProofRoute Dispatch Assurance

**Find the broken promise. Buy a verified rescue plan.**

The recommendation for the PayPal AI Hackathon is an AI-assisted dispatch audit and rescue service. A merchant imports an existing delivery plan, reviews source-grounded promises, and sees exactly where it fails under agreed travel-delay scenarios. PayPal authorizes $4.50 in sandbox. Local optimization produces one rescue route order, an independent checker verifies every frozen scenario, and capture/release follows only after the accepted result is stored.

**Start with [CLAUDE_HANDOFF.md](CLAUDE_HANDOFF.md).** It contains the read order and paste-ready implementation instruction. This workspace is a completed research/design package; **the application has not been built or tested.**

This repository is a **private research and planning archive**. It retains the public-source research captures so the citations and package audit remain reproducible. Third-party captures keep their original rights; review and remove them as needed before any public release. The future hackathon application requires its own licensed public-source package.

The flagship example is deliberately falsifiable: A→B→C travels4 km and passes nominal conditions, but B starts15 minutes late under CORRIDOR_DELAY. B→A→C travels4.4 km and passes all 3 frozen scenarios under4.5 km, with5 minutes minimum window margin. These numbers are independently checked **static design arithmetic**, awaiting actual model/solver/application reproduction. No traffic prediction or mileage-saving claim is implied.

The full product has 12 modules: intake, promise compiler, matrix provenance, audit, scenario lab, rescue solver, margins, remedies, lineage, PayPal settlement, evidence explorer and owner-scoped operator/agent access. Full first-build estimate **70–100 focused hours**; recommended flagship **44–58 hours**, including integration reserve. The deadline plan prioritizes the actual audit/rescue/payment workflow and cuts optional integrations early.

The deadline is **Friday November13,2026 at01:30 IST** = Thursday November12 noonPST =20:00UTC. The current event requires actual AI, meaningful free sandbox integration, a working runnable build, licensed public source and public YouTube video under 3 minutes. Five judging criteria have equal weight. The organizer asks entrants to freeze code/README/video after the deadline until announcement.
