# Search and retrieval log

## Method and limits

- Used the shared T3 browser to navigate the requested website and public search results. No private employee information or unpublished submission database was accessed. No product demo, competitor repository, payment transaction, or model benchmark was independently executed.
- Google result text supplied leads; an underlying page is evidence only when represented by an opened S-source. Queries below are reconstructed from Google query parameters in each saved page. Related-search query strings are not counted as searches actually performed.
- The official current gallery was unpublished. Indexed public Devpost project descriptions were read, so coverage is incomplete and entries can change. Searches with no match do not establish novelty.
- S18 and S37 are targeted section captures. S31 omits 7 characters relative to the reported page length. Other source captures preserve rendered page text rather than images, embedded video, source code, or exhaustive linked documentation. Some update cards are themselves collapsed excerpts.
- Search topics evolved from refunds/recalls to verified computational services after direct overlap was found. Rejected branches remain in the log.
- One unrelated result or related query shown by Google is not proof that the corresponding subject was investigated.
